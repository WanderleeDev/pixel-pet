Uso

React 19 pasa las propiedades de custom elements directamente. En React 18 usa @lit/react.

Vue necesita isCustomElement para no tratar pixel-pet como componente propio.

Svelte 5 funciona directo con custom elements, usando bind:this y $state.

Angular necesita CUSTOM_ELEMENTS_SCHEMA para aceptar el tag en plantillas.

Astro renderiza en servidor: el componente solo funciona en el cliente, así que usa el script del navegador.
